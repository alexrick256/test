# Japan Reiserechner (Shopify Section)

Eigenständige Section für Online Store 2.0 Themes – keine App, keine externen Abhängigkeiten.

## Installation
1. Shopify Admin → **Onlineshop → Themes → ⋯ → Code bearbeiten**
2. Ordner **sections** → **Neue Section hinzufügen** → Name `japan-reise-rechner`
3. Inhalt von `sections/japan-reise-rechner.liquid` einfügen, speichern
4. Theme-Editor → Seite öffnen → **Abschnitt hinzufügen → Japan Reiserechner**

## Anpassen
- Texte, Währung (EUR/CHF), Yen-Kurs, Button-Link und Farben im Theme-Editor.
- Preisannahmen (Hotel, Essen, JR Pass, Fahrpreise) stehen am Anfang des JavaScript-Blocks in der Datei.
